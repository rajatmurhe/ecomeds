# EcoMeds: Sustainable Healthcare E-Commerce

An end-to-end digital platform built to provide seamless access to wellness products, nutritional supplements, and everyday medical supplies.

This project tackles the modern challenge of online health retail by connecting a lightning-fast React Single Page Application with an optimized routing and state management system. By integrating a mobile-first design system, responsive UI components, and accessible navigation, this platform delivers a transparent, intuitive, and highly responsive user experience.

## Key Features
* **Instant Page Loads:** Bundled with Vite and built on React 18 for sub-second rendering and rapid interactions.
* **Responsive UI/UX:** Styled comprehensively with Tailwind CSS and `tailwind-merge` for adaptive, conflict-free layouts across all device sizes.
* **Client-Side Routing:** Utilizes React Router DOM to ensure seamless, flicker-free navigation between product catalogs and checkout flows.
* **Scalable Architecture:** Fully strictly typed with TypeScript, establishing a robust foundation for future API integrations and feature expansion.
* **Modern Iconography:** Integrated with Lucide React for crisp, lightweight, and scalable SVG interface icons.

---

## Tech Stack & Dependencies
* **Core:** React 18, TypeScript, Vite
* **Styling & UI:** Tailwind CSS, PostCSS, Autoprefixer, `clsx`, `tailwind-merge`
* **Routing:** React Router DOM v6
* **Deployment & Hosting:** Vercel (Configured with automated build pipelines)

---

The CI/CD pipeline has been optimized with explicit TypeScript configuration (tsconfig.app.json and tsconfig.node.json) to guarantee exact parity between the local development environment and the production server.
